# Validación visual pendiente

No se han realizado generaciones reales. Se necesitan una foto de cuerpo completo proporcionada por el propietario y fotos de sus prendas, una base de datos configurada y el procesador de Render Free con facturación de API habilitada. No usar fotografías de terceros como sustituto.

Para cada prueba, confirmar primero todas las prendas, solicitar un conjunto completo y generar una imagen desde “Verme con este look”. Registrar el ID del trabajo, modelo, fecha, resultado y coste disponible en el proveedor. El límite de solicitudes no permite calcular por sí solo el coste real.

Marcar aprobado solo si la persona sigue siendo reconocible y las prendas mantienen color, estampado y tipo de corte sin inventar piezas. Registrar cada discrepancia. Si la calidad no cumple, mantener la función como experimental y ajustar el prompt antes de volver a probar; no prometer una prueba de talla.

Prueba adicional de extremo a extremo: subir 30 fotos, revisar las etiquetas, filtrar por color/categoría, crear propuestas para las cinco ocasiones, planificar siete días con dos eventos en uno, sustituir una prenda, repetir una simulación sin aumentar el contador, eliminar referencias durante una generación y probar el acceso con una segunda cuenta. También verificar la retirada efectiva de archivos en Storage.
